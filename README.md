# Path Explorer — Upgraded

This is a standalone upgraded version of a pathfinding visualizer.

## New features

- BFS, DFS, Dijkstra, A*, Greedy Best-First
- Performance statistics
- Algorithm comparison mode
- Weighted cells
- Diagonal movement
- Multiple maze generators
- Algorithm information panel
- Responsive UI

## Run

Open `index.html` in a browser.

## Controls

- Left click: toggle wall
- Right click: toggle weighted cell
- Start and target are fixed in this version
- Choose an algorithm and click Visualize
- Use Compare Algorithms to compare visited nodes and path length

## Resume idea

**Path Explorer — Pathfinding Algorithm Visualizer & Performance Analyzer**
- Built an interactive pathfinding visualizer implementing BFS, DFS, Dijkstra, A*, and Greedy Best-First Search.
- Added algorithm performance comparison using nodes visited, path length, execution time, and path cost.
- Implemented weighted cells, diagonal movement, and multiple maze-generation strategies.
